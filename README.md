# AI-Powered-Chatbot-
The AI Powered Chatbot is an intelligent conversational web application developed using Large Language Models (LLMs) and AI API integration techniques.
Key Features

● Intelligent conversational AI responses
● Real-time chat interaction
● Responsive and modern user interface
● API-based Large Language Model integration
● Context-aware response generation
● Lightweight frontend-based implementation

Technologies Used

● HTML
● CSS
● JavaScript
● Groq API
● LLaMA 3.3
● VS Code
● GitHub

Working Flow

User Input → API Request → AI Model Processing → Intelligent Response Generation → Chat Interface Output

GitHub Execution

The project can be executed locally by opening the project folder in Visual Studio Code and running the index.html file using the Live Server extension.
